## 설치 방법

1. 위 링크에서 `hi-arm-win-x64.zip`을 다운로드하세요.
2. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 클릭하고 **모두 추출**을 선택하세요.
3. 압축을 푼 폴더에서 `hi-arm-win-x64.exe`를 실행하고 화면의 안내에 따라 설치하세요.
