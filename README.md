# HiARM Desktop 다운로드

HiARM Desktop의 Windows 설치 파일과 버전별 업데이트 내용을 제공하는 공식 배포 저장소입니다.

## 다운로드

- [Windows x64용 최신 버전 다운로드](https://github.com/hirobot-kr/hiarm-downloads/releases/latest/download/hi-arm-win-x64.exe)
- [최신 버전 업데이트 내용](https://github.com/hirobot-kr/hiarm-downloads/releases/latest)
- [제품 소개 및 시스템 요구 사항](https://www.hirobot.com/ko/hiarm/)

설치 파일은 `hi-arm-win-x64.exe`라는 이름으로 다운로드됩니다. 다운로드한 파일을 실행하여 설치하세요.

## 배포 안내

이 저장소는 설치 파일 배포용이며, HiARM Desktop의 소스 코드는 포함하지 않습니다.

최신 버전 다운로드 링크는 항상 최신 정식 릴리스의 설치 파일로 연결됩니다. 이전 버전은 [전체 릴리스 목록](https://github.com/hirobot-kr/hiarm-downloads/releases)에서 확인할 수 있습니다.

GitHub가 자동으로 표시하는 `Source code (zip)`과 `Source code (tar.gz)`는 이 배포 저장소의 문서 압축 파일이며, 앱 설치 파일이 아닙니다.

## 새 버전 배포 방법

1. 버전 번호가 포함된 원본 설치 파일을 준비합니다. 예: `hi-arm-1.1.0-win-x64.exe`.
2. 원본은 보관하고, 업로드할 복사본의 이름을 `hi-arm-win-x64.exe`로 지정합니다.
3. 새 릴리스를 만들고 버전에 맞는 태그(예: `v1.1.0`), 제목, 한국어 업데이트 내용을 입력합니다.
4. `hi-arm-win-x64.exe`를 첨부하고 업로드가 완료될 때까지 기다립니다.
5. 정식 배포는 사전 릴리스로 표시하지 않고, 최신 릴리스로 지정하여 게시합니다.
6. 로그아웃 상태에서 최신 버전 다운로드 링크가 정상적으로 작동하는지 확인합니다.

매번 새 릴리스를 만들고, 기존 릴리스의 설치 파일은 유지하세요. 업로드 파일명을 동일하게 유지하면 이후 앱 버전이 바뀌어도 하이로봇 웹사이트의 다운로드 링크를 수정할 필요가 없습니다.
